1What this box is

gauntlet is the medium machine in the set — a Debian VM with a PHP + MariaDB web app. The chain is SQL injection into credential cracking, then a two-step privilege escalation. The best test of methodology in the set.

Self-contained and offline once built. Runs on a laptop or a headless server VM.

2Requirements

# Debian / Ubuntu / Kali
sudo apt update && sudo apt install -y virtualbox vagrant

About 1 GB RAM and ~5 GB disk while building. Players will want rockyou.txt for the cracking step (ships with Kali).

3Build the box

cd m3-gauntlet
vagrant up

Export a portable .ova with the build script from the repo root:

./build-all.sh m3-gauntlet      # -> m3-gauntlet/lab-m3-gauntlet.ova

Note

The build disables the Vagrant provisioning account before export, so there is no build-time backdoor.

4Run it & get the IP

Import the .ova, set the adapter to a Host-only network (never expose it to the internet), and boot. Find the IP from the host:

sudo nmap -sn 192.168.56.0/24

That address is the challenger's <target-ip>.

Headless / server

VBoxManage startvm "lab-m3-gauntlet" --type headless

5Run an assessment

Give the player the <target-ip> and the challenger brief — challenger_instructions.html — which has the scenario, objective, rules, and a built-in flag checker. The solution is writeup.html (spoilers).

Reset between players with a snapshot:

VBoxManage snapshot "lab-m3-gauntlet" take clean
VBoxManage controlvm "lab-m3-gauntlet" poweroff
VBoxManage snapshot "lab-m3-gauntlet" restore clean
