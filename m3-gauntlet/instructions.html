1

What this box is

gauntlet is the medium machine — a Debian VM with a PHP + MariaDB web app. The chain is SQL injection into credential cracking, then a two-step privilege escalation. Players want rockyou.txt for the cracking step.

Self-contained and offline once built. Runs on a laptop or a headless server VM.

2

Requirements

On the host that builds the box:

$ sudo apt update && sudo apt install -y virtualbox vagrant

About 1 GB RAM and ~5 GB disk while building. The Debian base box downloads once and is reused across all boxes.

3

Build the box

From the repo root, build and export this box's .ova:

$ ./build-all.sh m3-gauntlet      # -> m3-gauntlet/lab-m3-gauntlet.ova

Or build it by hand without exporting:

$ cd m3-gauntlet
$ vagrant up

Note

The build disables the Vagrant provisioning account before export, so the finished machine has no build-time backdoor.
4

Run it & get the IP

Import the .ova in VirtualBox, set its network adapter to a Host-only network, and boot. Find its IP from the host:

$ sudo nmap -sn 192.168.56.0/24

Give that address to the player as their target.

Headless / server

Run with no GUI: VBoxManage startvm "lab-m3-gauntlet" --type headless.
5

Run an assessment

Give the player the target IP and the challenger brief — challenger_instructions.html — which has the scenario, objective, rules, and a built-in flag checker. The solution is writeup.html (spoilers).

Reset between players with a snapshot — instant, no rebuild:

$ VBoxManage snapshot "lab-m3-gauntlet" take clean
$ VBoxManage controlvm "lab-m3-gauntlet" poweroff
$ VBoxManage snapshot "lab-m3-gauntlet" restore clean
