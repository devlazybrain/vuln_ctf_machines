The scenario

"DevHub" is a catalogue of developer tools. The search box talks to a database, the developers took shortcuts, and the internal accounts were not locked down.

One machine, two flags. Getting root will take more than one step.

2

Your target

You are given the machine's IP — set it in the Target IP box above and it fills into the commands. Start by mapping it:

$ nmap -sC -sV <target-ip>
3

Your objective

Capture two flags and submit each exact string:

user flaga login on the box
root flagfull control of the machine

Flags look like FLAG{...}.

✓

Check your flags

Found a flag? Paste it in to verify. The answers are stored only as salted hashes, so this page checks your flag without ever revealing it.

4

Rules

  • Attack only the <target-ip> you were given.
  • Any tools are allowed — sqlmap, hashcat/john, and so on.
  • Keep notes on each step; being able to explain the chain is the point.
5

A nudge

If you get stuck

Find the parameter the database trusts and take what it stores. Those secrets won't be usable as-is — turn them into something you can log in with. For root, one account can act as another, and somewhere an ordinary-looking binary has more power than it should.
