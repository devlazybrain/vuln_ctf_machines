FlagTrail — Launch Instructions

How to import, network, and boot the FlagTrail-Linux-CTF.ova appliance in VirtualBox, then hand it to candidates.

Once you know the box's IP, set it here — it fills <IP> in the commands below and in Copy. Saved only in this browser.

⚠️ Host-only use only. This VM is intentionally vulnerable. Never attach a bridged adapter or expose it to the internet, and never reuse its credentials anywhere.

Setup

1

Import the appliance

VirtualBox → File → Import Appliance… → select FlagTrail-Linux-CTF.ova → Next → Finish. Wait for it to unpack (a minute or two).

CLI equivalent:

VBoxManage import FlagTrail-Linux-CTF.ova
2

Confirm Host-only networking

Select the VM → Settings → Network → Adapter 1. It should be Host-only Adapter (e.g. vboxnet0). If you have no host-only network yet, create one in Tools → Network → Host-only Networks → Create, then make sure its DHCP server is enabled.

Why host-only

It puts the target and the candidate's attack box on a private lab segment they can reach, with no path to your real network or the internet.

CLI equivalent:

VBoxManage modifyvm "FlagTrail-CTF" --nic1 hostonly --hostonlyadapter1 vboxnet0
3

Boot it

Start the VM. It boots headless to a login prompt — you do not log in at the console; everything is done over the network by the candidate. Give it ~30 seconds to get a DHCP lease.

4

Find its IP (and give it to the candidate)

From your host or the candidate's attack box on the same host-only net:

# sweep the host-only subnet (adjust if yours differs)
nmap -sn 192.168.56.0/24
# the target answers on 80/22/445
nmap -p 22,80,445 192.168.56.0/24 --open

Hand the candidate only the IP (and, if you like, the hint that an SMB share exists). Everything else they must discover.

Running the challenge

5

What the candidate does

  • Points a browser / curl at http://<IP>/ and enumerates.
  • Pulls the brief from the anonymous SMB share: smbclient //<IP>/public -N.
  • Works the chain to root and submits each flag in the Flag Checker page (challenger_instructions.html).

The checker validates flags by salted hash locally — candidates can't read the answers from its source.

Reset between candidates

6

Snapshot & roll back

Before the first run, take a snapshot. After each candidate, roll back so everyone gets an identical box.

# once, before the first candidate:
VBoxManage snapshot "FlagTrail-CTF" take clean --description "pristine"
# after each candidate — power off, then roll back:
VBoxManage controlvm "FlagTrail-CTF" poweroff
VBoxManage snapshot "FlagTrail-CTF" restore clean

The flags are fixed, so a roll-back is optional — but it clears any mess a candidate left behind.

Troubleshooting

VM has no IP

The host-only network's DHCP server is probably off. Enable it under Tools → Network → Host-only Networks → (your net) → DHCP Server, then reboot the VM.

Can't reach it from the attack box

Make sure the attack VM is on the same host-only adapter (vboxnet0), not NAT.

Import warns about MAC / adapter

Safe to accept defaults. Just re-check Adapter 1 = Host-only before booting.
