1

What this box is

FlagTrail is the hard, six-flag machine — a Debian 13 VM with a deliberate chain from anonymous web recon through an SSH foothold and a localhost-only service to a root privilege escalation. Only the vulnerabilities needed for those six flags are present.

Self-contained and offline once imported. Runs on a laptop or a headless server VM.

2

Get the image

The built appliance ships as FlagTrail-Linux-CTF.ova in this folder. If you downloaded it from GitHub Releases (split to fit the 2 GB asset cap), reassemble and verify first:

$ cat FlagTrail-Linux-CTF.part00.ova FlagTrail-Linux-CTF.part01.ova > FlagTrail-Linux-CTF.ova
$ sha256sum -c FlagTrail-Linux-CTF.ova.sha256     # should print: OK

Rebuild from source (optional)

The box is also reproducible from provision/ (an unattended Debian install via build_ova.sh). You don't need this unless you want to change it.
3

Import & network

Import the appliance into VirtualBox:

$ VBoxManage import FlagTrail-Linux-CTF.ova

Then set Adapter 1 = Host-only before first boot (GUI: Settings → Network). Do not use bridged.

4

Boot & get the IP

Boot it, then find its IP from an attacker box on the same host-only network:

$ sudo nmap -sn 192.168.56.0/24

Give the player only that IP (and that an SMB share exists).

Headless / server

Run with no GUI: VBoxManage startvm "FlagTrail-CTF" --type headless.
5

Run an assessment

Hand the player the target IP and the challenger brief — challenger_instructions.html — which has the scenario, objective, and a flag checker for all six flags. The solution + recruiting rubric is writeup.html (spoilers).

Reset between players with a snapshot — instant, no re-import:

$ VBoxManage snapshot "FlagTrail-CTF" take clean
$ VBoxManage controlvm "FlagTrail-CTF" poweroff
$ VBoxManage snapshot "FlagTrail-CTF" restore clean
