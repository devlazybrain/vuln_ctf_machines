1

What this box is

recovery is the easy, first machine in the set. It is a single Debian Linux VM running a few network services. Your job is to enumerate it, find a foothold, and escalate to root — capturing a user flag and a root flag along the way.

It is fully self-contained and offline: once built it needs no internet. Safe to run on a laptop or a headless server VM.

2

Requirements

On the host that builds the box:

# Debian / Ubuntu / Kali
sudo apt update && sudo apt install -y virtualbox vagrant

Roughly 1 GB RAM and ~5 GB disk while building. The first build downloads the Debian base box once (~500 MB) and reuses it.

3

Build the box

From the repo's machines/ folder, build just this box:

cd machines/m1-recovery
vagrant up            # builds + provisions the VM

To export a portable .ova you can hand to anyone, use the helper from machines/:

cd machines
./build-all.sh m1-recovery      # -> machines/ova/lab-m1-recovery.ova

Note

The build disables the Vagrant provisioning account before export, so the finished machine has no build-time backdoor.
4

Run it & get the IP

Import the .ova in VirtualBox (or boot the Vagrant VM), set its network adapter to a Host-only network so it is never exposed to the internet, then boot it.

Find the box's IP from the host:

sudo nmap -sn 192.168.56.0/24     # your host-only subnet

That address is your <target-ip> for the attack.

Headless / server

To run it on a server with no GUI: VBoxManage startvm "lab-m1-recovery" --type headless.
5

Objective & rules

Capture two flags:

  • a user flag — standing access as a normal user
  • a root flag — full control of the machine

Flags look like FLAG{...}. Only attack the target IP you were given. Any tools are fair game (nmap, forensic carvers, etc.).

Hint: think about what a backup really contains — "deleted" is not the same as "gone."
