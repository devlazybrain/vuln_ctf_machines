Vulnerable Linux Boxes

Four self-contained, intentionally vulnerable Debian machines — easy to hard — for hands-on practice, exams, or self-training. Each has flags, a built-in flag checker, and a full write-up.

How it works. Import a box's .ova, set it to a host-only network, and attack the IP. Read the host page to run it, hand a player the challenge page, and open the write-up only when you want the solution.

Get the images from Releases (too large for the repo), import with VBoxManage import <box>.ova, and run. No build step needed.
